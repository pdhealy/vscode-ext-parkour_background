# Product Requirements Document (PRD) for "Background Image" VSCode Extension

I want to create a Visual Code (VSCode) extension called "Background Image". This extension will set the background of their selected code editor window to an image of a cat. The image of the cat will be 70% transparent, allowing the code to be visible while still providing a visually appealing background. The extension will allow users to easily customize their coding environment and add a touch of personality to their workspace. 
Users will be able to enable or disable the background image as needed, and the extension will be lightweight and efficient, ensuring that it does not negatively impact the performance of the code editor.
The user will be able to enable or disable the background image through a simple toggle in the extension settings, or via the Command Pallette, or via right-clicking on the open code editor window with a custom option in the context menu.
Overall, "Background Image" will provide a fun and customizable way for developers to enhance their coding experience in VSCode.
The image of the cat can be found in Private/dev_projects/vscode/extensions/parkour_background/assets/image.png. The extension will be developed using TypeScript and the VSCode Extension API, ensuring compatibility with the latest versions of VSCode. The extension will be published on the Visual Studio Code Marketplace, making it easily accessible to developers around the world.
The background image must only be applied to the code editor window, and not to other parts of the VSCode interface such as the sidebar or terminal. This will ensure that the extension does not interfere with the overall functionality of the code editor and allows users to maintain a clear view of their code while still enjoying the visual enhancement provided by the background image.
The background image should only be displayed in the active code editor window, and should not be applied to any other open windows or tabs in VSCode. This will ensure that users can have a consistent experience across all their open windows and tabs, while still allowing them to enjoy the visual enhancement provided by the background image in their active code editor window.
